## Introduction

`reflect-linker` is a lightweight library focused on object access.

You only need to define an interface and declare field expressions or method expressions on the interface methods. At runtime, the framework generates the corresponding implementation class and turns logic that would normally require handwritten reflection into a directly callable linker.

It works well in scenarios such as:

- Accessing private fields, private methods, static fields, and static methods
- Repeatedly traversing object methods and fields through reflection-like access
- Certain `javaagent` use cases

## Features

- Supports field reads, field writes, method calls, and constructor calls
- Supports chained field expressions and method expressions
- Supports nested expressions, null-safety, and indexed access
- Seamless linker object usage with `@Autolink`
- `@ImportStatic` imports static methods/fields of helper classes into the lookup process

## Installation

Requirement: JDK 8+

```xml
<dependency>
    <groupId>io.github.hhy50</groupId>
    <artifactId>reflect-linker</artifactId>
    <version>2.0.0</version>
</dependency>
```

## Core API

- `LinkerFactory.createLinker(Class<T> define, Object target)`: links to a target object
- `LinkerFactory.createStaticLinker(Class<T> define, Class<?> targetClass)`: creates a static linker that can operate on static fields and static methods

For debugging:

- `LinkerFactory.setOutputPath(String path)`: outputs generated bytecode to the specified directory

## Quick Start

Here is the simplest example: access object fields and methods through an interface.

```java
import io.github.hhy50.linker.LinkerFactory;
import io.github.hhy50.linker.annotations.Field;
import io.github.hhy50.linker.exceptions.LinkerException;

interface UserLinker {
    @Field.Setter("name")
    void setName(String name);

    @Field.Getter("name")
    String getName();

    @Field.Getter("address")
    String getAddress();

    // Without an annotation, it is treated as a call to a method with the same name by default.
    String hello(String prefix);
}

class User {
    private String name;
    private String address = "Hangzhou";

    private String hello(String prefix) {
        return prefix + ", " + name;
    }
}

public class Example {
    public static void main(String[] args) throws LinkerException {
        UserLinker linker = LinkerFactory.createLinker(UserLinker.class, new User());
        linker.setName("reflect-linker");

        System.out.println(linker.getName());
        System.out.println(linker.getAddress());
        System.out.println(linker.hello("Hi"));
    }
}
```

## Core Annotations

| Annotation                                            | Purpose |
|-------------------------------------------------------|---------|
| `@Field.Getter("expr")`                             | Reads a field, with support for chaining, null-safety, and indexes |
| `@Field.Setter("expr")`                             | Writes a field, with support for chaining to the final field |
| `@Field.StaticGetter("expr")`                       | Reads a static field |
| `@Field.StaticSetter("expr")`                       | Writes a static field |
| `@Method.Expr("expr")`                              | Explicitly declares a method expression |
| `@Method.Constructor`                                 | Maps an interface method to a target class constructor |
| `@Method.InvokeSuper("xxx")`                        | Calls the specified superclass implementation |
| `@Typed(name = "token", value = "full.class.Name")` | Assigns a more precise type to a token in an expression |
| `@Runtime`                                            | Marks the interface for runtime resolution mode |
| `@Runtime.Static`                                     | Treats certain runtime fields/methods as static members |
| `@Autolink`                                           | Automatically wraps/unwraps parameters or return values as linkers |
| `@ImportStatic`                                       | Adds static methods/fields of the given classes to the lookup process (this wins) |
| ~~`@Target.Bind("full.class.Name")`~~               | ~~Explicitly binds the target class~~ |

### `expr` Examples

| Expression | Description |
|------------|-------------|
| `name` | Accesses the `name` field of the target object |
| `user.address.city` | Accesses nested fields in sequence |
| `users[0].name` | Accesses a field of the first array or `List` element |
| `usersById['admin'].name` | Accesses a `Map` value by key and then reads its field |
| `user?.address.city` | Returns the default value if `user` is `null` |
| `getUser().getName()` | Invokes methods in a chain |
| `findUser($0)` | Passes the first interface method argument to the target method |
| `merge($0, $1)` | Passes multiple interface method arguments by index |
| `merge(..)` | Forwards all interface method arguments in declaration order |
| `format(user.name, 'VIP', 1)` | Uses a nested expression and string/integer constants as arguments |

See [Expression Usage](USAGE.md) for detailed behavior.

## Other Common Capabilities

### Constructor mapping

```java
import io.github.hhy50.linker.annotations.Method;
import io.github.hhy50.linker.annotations.Target;

@Target.Bind("java.util.ArrayList")
interface ArrayListLinker {
    @Method.Constructor
    ArrayListLinker newList();

    @Method.Expr("add(..)")
    void add(Object value);
}
```

### Call a specified superclass implementation

```java
interface FatherVisitor {
    @Method.InvokeSuper("your.pkg.Father1")
    @Method.Expr("aaa()")
    String father1Aaa();
}
```

### Import static members with `@ImportStatic`

`@ImportStatic` adds the static methods/fields of a helper class to the lookup process.

```java
import io.github.hhy50.linker.annotations.ImportStatic;

class MyStringUtil {
    public static String trim(String s) {
        return s.trim();
    }
}

@ImportStatic(MyStringUtil.class)
interface MyLinker {
    // The same-name call is resolved to the imported static method MyStringUtil.trim.
    String trim(String s);
}
```

`@ImportStatic` can be placed on the interface (applies to all methods) or on a single method (overrides the class-level import). See [Expression Usage](USAGE.md) for details.

## Debug Generated Bytecode

If you want to inspect the linker implementation classes generated by the framework, set an output directory first:

```java
LinkerFactory.setOutputPath("generated-linkers");
```

Then call `createLinker(...)` / `createStaticLinker(...)`, and the generated `.class` files will be written to that directory.
